## Reference setup (what the numbers above were measured on)

Device
- AYN Thor (Pro, 12 GB): QCS8550, 11.5 GB RAM reported, device codename `kalama`
- Firmware `Thor_V1.0.0.377_20260206_165408_user`, Android 13 (API 33), security patch 2024-01-01
- Main panel 1080x1920 (landscape use), running at **120 Hz** (system default); second panel 1080x1240 @120 Hz
- Navigation: gesture mode (`navigation_mode=2`)
- Second-display shell: Cocoon Shell 3.04 installed (the app draws its own Presentation; Cocoon Shell was not needed for the second screen but was present)
- USB debugging on; device otherwise stock

ROM
- Metroid Prime Hunters, USA rev 0 (`AMHE`), 64 MiB, SHA-1 `90164d1ac127ee5f9815ea4ae7de798c7b5fc629`, dumped from the owner's cartridge

App / engine build
- App: HuntersRecomp `52f8233` (versionName 0.2.4 test build, versionCode 7), release-signed, `-O2`
- Engine: aabrole/ndsrecomp branch `v022-golden` at `e4749e6`
- Bank generator: MetroidPrimeHuntersRecomp branch `thor-golden` at `17f46d0` (upstream 7e472a5 + Thor seeds); banks regenerated from the ROM above, including the ARM9 ITCM alias bank and 24 runtime banks captured on this device (images not committed; a fresh build without them will be slower until its own coverage loop runs)
- Toolchain: Android NDK 27.2.12479018, SDL2 2.30.11, GLES 3.2 compute renderer

In-app settings used
- Internal resolution 3x (1344x576); texture upscaling xBR 4x; bottom screen Original 4:3
- Right-stick aim sensitivity 55%, virtual stylus 20%, invert Y as preferred (it was ON on the dev unit)
- Show FPS counter ON; button bindings at defaults
- Runner flags the app passes: `--mph-prime-controls on --relative-mouse-touch on --screen-layout stacked --freebios --boot direct --generated-firmware --diagnostics on --discover-static-misses`, emulation thread pinned to cpu5-7
